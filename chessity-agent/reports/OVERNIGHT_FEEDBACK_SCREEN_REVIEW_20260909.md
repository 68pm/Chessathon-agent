# Exact evidence review for a completed short screen

The old promotion helper is specific to the cancelled40-game programme and must
not be invoked for this overnight task. This new read-only evidence reviewer
checks the completed portable screen, exact candidate/control manifests, ZIP
members, read-only validation and every game's completed feedback checkpoint.
It does not start games, run engines, refit weights, publish or select a release.

Recalculate wins/draws/losses by exact candidate, opponent setting and colour.
Keep operational results in the totals, but exclude flag/crash/illegal/startup
wins from the highest clean nominal opponent beaten. Require nominal setting
labels to match the actual scheduled setting. Validate the predeclared ascent
order and clean-win/no-failure condition before accepting a higher stage.

Include all move-review counts and specific phase-aware diagnostic roots from
the fixed curriculum planner. Never sum repeated replay checkpoint example
counts into a claim of distinct training games. Experimental checkpoint updates
remain separate from frozen playing weights. No numerical Elo estimate is
invented. Distinguish a favourable four-game score from a tie and preserve both
colour results; neither implies established consistency.

Reject partial or failed screens for automatic report preparation; inspect their
saved games explicitly instead of silently omitting an unfinished/failed stage.
Only create release-evidence-01 after the entire screen is complete. All sources
are hashed and existing outputs are preserved. A separate final decision must
consider the complete comparison, rated results, previous selection and remaining
weaknesses before any upload recommendation changes.
